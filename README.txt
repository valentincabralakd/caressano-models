CARESSANO MODELS AGENCY — V5

Estructura de dos páginas:
- index.html: portada de una sola pantalla. Banner principal + breve bloque de historia/agencia + contacto/casting. Sin selección de modelos.
- models.html: segunda página con selección de modelos y contacto/casting.
- modelo.html: perfil individual de cada modelo.
- admin.html: panel DEMO LOCAL para editar textos y modelos.
- styles.css: diseño responsive para PC, tablet y celular.
- app.js / admin.js: datos, edición local y navegación.

La portada prioriza una experiencia compacta y visual, evitando el scroll permanente. La segunda página concentra el board de modelos y la información de contacto.

IMPORTANTE: el panel de administración usa localStorage del navegador y es solo un prototipo. Para publicar habrá que reemplazarlo por backend, base de datos, almacenamiento de imágenes y autenticación segura.
